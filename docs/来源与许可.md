## 免责声明

本插件会执行以下操作，请自行评估风险：

- 读取 `/proc/bus/input/devices` 与 `/sys/class/input/*` 识别输入设备
- 通过 `lipc-set-prop` 控制背光与电源状态（熄屏 / 唤醒）
- 启动与停止 KindleBTH 进程
- 改写 `KindleBTH/bin/config.json`（改写前会备份）

对设备做越狱、修改系统分区、安装第三方驱动均存在风险。
本插件按“现状”提供，不对设备损坏、数据丢失或任何间接损失承担责任。
