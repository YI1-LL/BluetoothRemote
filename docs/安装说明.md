# 蓝牙翻页器助手 · 安装说明

> 本包**只包含插件本身**，不含任何第三方代码。
> 需要你先自行装好两个上游组件，再装这个插件。

---

## 一、包里有什么

```
蓝牙翻页器助手/
├── 安装说明.md          ← 本文件
├── 来源与许可.md
└── BluetoothRemote/     ← 插件本体，整个文件夹放进 extensions
```

## 二、前置：两个上游组件

这两个是**别人做的**，本包不转载，请从原始发布处获取。

### ① kindle_hid_passthrough（蓝牙底层驱动）

- 作者：Lucas Zampieri
- 地址：https://github.com/zampierilucas/kindle-hid-passthrough
- 许可：GPL-3.0
- 作用：把蓝牙翻页器变成系统能识别的输入设备

**装好后应该在：**

```
Internal Storage\kindle_hid_passthrough\
```

### ② KindleBTH（翻页动作执行器）

- 作者：de1eteit（改自 llakssz 的 KindleLazy）
- 版本：0.0.2
- 许可：作者未声明（本包不转载，请自行获取）
- 作用：读按键，执行翻页 / 亮度 / 熄屏

**装好后应该在：**

```
Internal Storage\extensions\KindleBTH\
```

> 这两个组件目前没有官方应用商店，通常从相关教程帖、论坛或群文件获取。
> 本包不提供下载，避免版权问题。

### ③ 先配对一次

用 Kindle 自带的蓝牙管理器，或 `kindle_hid_passthrough` 附带的 **BTManager**，
把你的翻页器配对一次。配对记录会写进 `kindle_hid_passthrough\devices.conf`。

## 三、装本插件

1. USB 线连 Kindle 和电脑
2. 电脑打开「此电脑」→ 双击 **Kindle** 盘（Internal Storage）
3. 进入 `extensions` 文件夹
4. 把本包里的 **`BluetoothRemote`** 整个文件夹拖进去

放好后的完整路径：

```
Internal Storage\extensions\BluetoothRemote\
```

5. 安全弹出，拔线
6. 打开 KUAL，应该能看到 **「蓝牙翻页器助手」**

> 看不到？检查是不是多套了一层：
> 打开 `BluetoothRemote` 文件夹，应该**直接**看到 `config.xml`。

---

## 四、首次使用

```
① KUAL → 蓝牙翻页器助手
② 只有一个选项：[0] 初始化 / 刷新菜单，点它
③ 退出 KUAL 再进一次
④ 这时出现完整菜单
```

完整菜单长这样：

```
[0] 刷新状态
<你当前连着的翻页器名字>
[1] 上一页  (点这里开始匹配)
[2] 下一页  (点这里开始匹配)
[3] 熄屏（再按一下亮屏）
[4] 亮屏（同上）
[5] 全部完成，启动翻页服务
[6] 翻页来回跳？点这里修复
[7] 查看当前键位绑定
[8] 恢复出厂键位（重学一遍）
```

## 五、绑定按键（重点）

### 绑一个键的完整流程

以「上一页」为例：

```
① 点 [1] 上一页
② 屏幕倒数：3 → 2 → 1
③ 出现 PRESS PREV PAGE 后，
   在 12 秒内连续按翻页器上的「上一页」键约 10 下
④ 屏幕出现：
     [ OK ] MAPPED
     PREV PAGE = key 312
⑤ 按 Home 退出 KUAL，再重新进
⑥ 菜单里 [1] 变成：上一页  已匹配: 312
```

对 `[2] 下一页` 重复一次。

### 关于 [3] 熄屏 和 [4] 亮屏

Kindle 的电源键是「按一下关、再按一下开」的同一个键，
所以 `[3]` 绑好后，按一下关屏、再按一下亮屏，`[4]` 不需要单独学。

点 `[4]` 只会弹出提示，告诉你当前用的是哪个键码。

### 最后一步

```
[5] 全部完成，启动翻页服务
```

等屏幕出现 `READY`，然后打开一本书试试翻页。

## 六、常见问题

**按了没反应？**

1. 看 `[0]` 下面那行是不是你正在用的翻页器（不是就去 BTManager 里连）
2. 点 `[5] 启动翻页服务`
3. 点 `[7] 查看当前键位绑定`，确认你按的键码在列表里

**翻一页又翻回来？**

同一个键码被两个动作同时占用了。点 `[6] 修复冲突`。

**有几个键配不上，一配就把别的弄坏？**

有些翻页器/手柄的多个按键发出的**是同一个键码**，系统层面无法区分。
这种情况一个码只能绑一个功能，请换一个发码不同的键（肩键、摇杆按下通常比较独立）。

**学完菜单没变化？**

KUAL 只在启动时读菜单文件，**必须退出 KUAL 再进**。这是 KUAL 的限制。

**熄屏没反应？**

先确认 `[5]` 启动了服务，并且设备前光不是处于异常值（前光为 0 时看起来像没反应）。

## 七、卸载

```
① 删除 Internal Storage\extensions\BluetoothRemote\
② 退出 KUAL 再进，菜单里就没有了
```

上游的两个组件（`kindle_hid_passthrough`、`KindleBTH`）如需卸载，请参考它们各自的说明。
